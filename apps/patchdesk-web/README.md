# PatchDesk workbench

React/TypeScript/Vite client for the same-origin scoped API. Ink/cream/amber maintenance workspace with client grouping, paired file import, conversation, cited findings/conflicts, candidate checks, activity/capability views, revision-bound review/export and explicitly approved optional issue publication.

From repository root: `npm --prefix apps/patchdesk-web ci`, `npm --prefix apps/patchdesk-web test`, `make patchdesk-up`. Build/presentation tests pass; browser visual/keyboard/viewport acceptance remains open.
